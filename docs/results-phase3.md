# Phase 3 results: conformal recall control on the zero-shot baseline

Generated by `src/conformal.py` from commit `38f4aa5` (dirty=False). Calib: `results/baseline-calib-f001` (floor 0.01); val: `results/baseline-val-full-f001` (floor 0.01); test: `results/baseline-test` (floor 0.05).

## Definitions

- **Found:** a person is found at threshold λ if some kept box (score ≥ λ) has IoU ≥ 0.3 with their label. Centre-inside and IoU ≥ 0.5 variants use the same any-box rule.
- **Frame-averaged recall (headline):** the mean over frames of the fraction of that frame's people found. This is the quantity the conformal guarantee controls: expected per-frame miss rate ≤ α = 1 − target.
- **Pooled person recall (secondary):** people found divided by all people. Crowded frames weigh more, so it is usually lower.
- **Precision and false boxes:** one-to-one greedy matching at IoU ≥ 0.3.
- **Ranges:** 2.5–97.5% block-bootstrap percentiles (2000 resamples of whole 40-frame blocks). They are **descriptive**: val has 6 blocks and test has 7.
- **Test is confirmatory only.** Nothing is chosen on test. `worst-block` was introduced *after* the `crc-frame` test shortfall had been seen, so its test result is not a clean held-out confirmation of that design choice.
